HTML SLIDE KIT

話す順に見せる、
日本語の投影スライド

HTML 1 枚で作って、そのまま発表・PDF・公開

しらとり なるひこ（narupeko）

FEATURES

このキットでできること

  • 1280×720 で作り、画面に合わせて拡大縮小。印刷すれば 1 枚 1 ページの PDF
  • クリックや → で1 段ずつ出す。全部出たら次のスライドへ
  • クイズ、話し合いタイマー、投票の QR で、聞き手が参加できる
  • 文字を順に出す、下線と数え上げ、レーザー（L）、全画面（F）

HTML スライドキット05
HOW TO

書き方は属性を足すだけ

<!-- 1 回目のクリックで出る --> <p data-step="1">…</p> <!-- 子を 350ms ずつ順に出す --> <div data-cascade="350">…</div> <!-- 子をクリックごとに 1 つずつ --> <ul data-each="1">…</ul> <!-- 下線を引く・数え上げる --> <span class="uline" data-step="2">…</span> <b data-count="3212">3,212</b>
  • data-step="0" はスライドに入ったとき自動で出る
  • 戻って入ったスライドは、全部出た状態で見せる
  • 印刷・PDF では最初から全部出る

QUIZ

まず予想してから

このキットで、1 枚のスライドに入れる段はいくつまで？

  1. 2 段まで
  2. 4 段まで
  3. 8 段まで

多すぎると、聞き手も話し手も迷子になる。答えを先に言わず、指で答えてもらってからクリックする。

HTML スライドキット09
VOTE

スマホで答えてもらう

このスライドを手元で開く
  • data-url に投票ページの URL を入れると、QR コードと URL が出る
  • 結果ページは <iframe class="live-frame"> で埋め込める
  • 投票の仕組みは、自前の Worker・Slido・Mentimeter・Google フォームなど何でもよい
HTML スライドキット10
DESIGN

参加の場面を、先に決める

01

最初の 5 分で 1 問

自己紹介より先に聞いてもよい。答えてよい場だと伝わる

02

15 分に 1 回

クイズ、話し合い、投票、振り返りを入れ替えて使う

03

予想、結果、なぜ

答えを見せたら「なぜそう思った？」を 1〜2 人に聞く

HTML スライドキット11
PUBLISH

作ったスライドを公開する

  • GitHub Pages：リポジトリに置いて Pages を有効にするだけ
  • Cloudflare Workers：静的ファイルとして npx wrangler deploy。手順は README
  • 公開する前に、個人情報と組織の実データを外す。参加者の自由記述は要約にする
